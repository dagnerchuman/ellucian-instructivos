# Documentos

Entregables y documentos del proyecto, ordenados por tipo. Los generadores de los PDF, Word y PPTX están en `.claude/skills/documentos-uss/fuentes/`.

| Carpeta | Qué hay |
|---|---|
| [`dudas/`](dudas/README.md) | **Preguntas para Ellucian y la USS** en Word, con un recuadro de respuesta por pregunta. Se responden en Word y se devuelven para alimentar el registro |
| `afiches/` | Afiches para estudiar los términos de Banner: el de Centros Empresariales y el general (PDF, una hoja A4) |
| `capacitacion/` | Dossier de capacitación de las capacidades 1, 5 y 7 y la actividad práctica de periodos académicos |
| `arquitectura/` | Arquitectura operativa y scripts avanzados de los centros (22/10) y la skill de Computación exportada a PDF. La versión vigente de la skill es `.claude/skills/centro-computacion/SKILL.md` |
| `presentaciones/` | Presentaciones PPTX: «2. Programación de asignaturas» |
| `fuentes/guia-operativa-excel/` | Hojas de la guía operativa descargadas en CSV (crear el NRC, persona, admisión, matrícula, notas). Son la fuente de las guías de `arquitectura-centros-empresariales/references/` |
| `propuesta-usuarios-finales/` | Borrador interno de la propuesta de usuarios finales para Pedro Pérez Martinto. **Todavía no se envía**: ver el aviso al inicio del archivo |

**Publicación:** el sitio (https://centros-empresariales-ellucian.vercel.app) se publica desde la rama `main`. Si estos documentos llegan a `main`, quedan visibles en el sitio; la propuesta de usuarios finales no debe ir sin confirmarlo con el usuario ([ADR-016](../conocimiento/decisiones/ADR-016-confidencialidad-y-publicacion.md)).
