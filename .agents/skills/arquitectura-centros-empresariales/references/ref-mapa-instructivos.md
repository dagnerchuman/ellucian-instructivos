# Mapa de instructivos del repositorio

Instructivos de Ellucian (PPTX) por capacidad. Entre paréntesis, el número de diapositivas. Busca texto con `scripts/buscar_instructivos.py`.

El visor web (`visor_instructivos/`) muestra estos PPTX en el navegador; Netlify lo publica con `publish = "."` y la raíz redirige al visor.
