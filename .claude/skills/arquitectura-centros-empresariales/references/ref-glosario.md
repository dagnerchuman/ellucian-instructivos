# Glosario: siglas y páginas de Banner

Regla del usuario (26/09/2026): toda sigla o código va con su significado entre paréntesis, por ejemplo «NRC (Número de Referencia de Curso)».
Los PDF lo hacen solos con `explicar()` de `documentos-uss/scripts/pdf/common.py`: se explica la primera vez en cada tarjeta y se agrega un glosario.
Este archivo sale de los diccionarios `SIGLAS` y `PAGINAS` de ese mismo archivo. Si agregas un término, hazlo allí y vuelve a generar este archivo.

## Siglas y palabras

| Término | Corto (entre paréntesis) | Significado |
|---|---|---|
| ATTRGRD | componente de asistencia | Nombre obligatorio del componente de asistencia en el plan de evaluación del NRC. |
| autoservicio | portal web de Banner para docentes y estudiantes | Portal web de Banner para docentes y estudiantes. |
| backoffice | páginas internas de Banner que usa el personal | Páginas internas de Banner que usa el personal administrativo. |
| CAPP | evaluación del avance en la malla | Curriculum, Advising and Program Planning: compara la historia académica con la malla y muestra qué cursos cumplió el estudiante y cuáles le faltan. |
| EG | Egresado | Estado de Egresado del estudiante de pregrado. |
| FTE | equivalente a tiempo completo | Full-Time Equivalent: cuántas horas equivalen a un docente a tiempo completo. |
| INH | nota de desaprobado por asistencia | Código de nota de desaprobado por asistencia en el ejemplo del instructivo 7.1.0. |
| LMS | plataforma del aula virtual | Learning Management System: plataforma del aula virtual. |
| NRC | Número de Referencia de Curso | Número de Referencia de Curso: identifica un grupo o sección de un curso en un periodo, con su horario y sus docentes. |
| pitch | presentación corta del proyecto | Presentación corta del proyecto o plan de negocio. |
| SEUSS | sistema académico actual de la USS | Sistema académico que la USS usa hoy y que se reemplaza por Banner. |

## Grupos y periodos

- **I01…I12 / X01…X12 / P01…P12:** partes de periodo (grupos del mes) de Idiomas, Computación y Emprendimiento.
- **IGE / CGE / EGE:** parte de periodo general de cada centro.
- **2026 5 4:** código de periodo: año + nivel 5 (Centros Empresariales) + secuencia (1 verano, 4 semestre I, 6 semestre II).
- **Fatal / Alerta / No verificar:** severidad de cada verificación de inscripción en SOATERM (Fatal impide inscribir).
- **Sobrepaso:** permiso para inscribir a pesar de un error de inscripción (SFAROVR).
- **PROD / TEST:** ambientes de Banner: producción y pruebas.
