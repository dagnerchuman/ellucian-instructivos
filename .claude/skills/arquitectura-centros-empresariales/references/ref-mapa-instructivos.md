# Mapa de instructivos del repositorio

Instructivos de Ellucian (PPTX) por capacidad, con su código, su nombre completo y el número de diapositivas. Cuando varios comparten código (5.3, 5.4, 8.1, 10.2), los distingue el procedimiento de Ellucian. Se citan así: «instructivo 5.3, Registrar la oferta horaria de los cursos, diap. 23».

El nombre de archivo de cada uno (algunos vienen cortados) está en `herramientas/diagramas/catalogo_instructivos.py`, que relaciona archivo, código y nombre. Busca texto con `scripts/buscar_instructivos.py`. El visor web (`visor_instructivos/`) los muestra como imágenes; el sitio se publica desde `main`.
